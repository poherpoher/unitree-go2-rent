Политика конфиденциальности

Настоящая Политика конфиденциальности персональных данных действует в отношении всей информации, которую данный сайт может получить о Пользователе во время использования ресурса.

1. Общие положения

1.1. Использование сайта означает согласие Пользователя с настоящей Политикой конфиденциальности и условиями обработки его персональных данных.

1.2. В случае несогласия с условиями Политики Пользователь должен прекратить использование сайта.

2. Собираемые данные

2.1. Мы не собираем намеренно персональные данные (ФИО, паспорта, телефоны), кроме случаев, когда пользователь добровольно указывает их в формах обратной связи.

2.2. Сайт использует технологию `localStorage` исключительно для сохранения выбранной пользовательской темы (темная/светлая), чтобы сайт открывался в комфортном для вас режиме.

3. Цели сбора информации

3.1. Технические данные используются исключительно для обеспечения корректного функционирования интерфейса сайта, анализа производительности и удобства использования.

4. Защита информации

4.1. Администрация сайта принимает необходимые организационные и технические меры для защиты персональной информации пользователя от неправомерного доступа.

5. Заключительные положения

5.1. Все предложения или вопросы по поводу настоящей Политики следует сообщать через раздел контактов.
